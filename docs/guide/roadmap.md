# Rivojlanish Yo'l Xaritasi (Roadmap)

Mitti tili bosqichma-bosqich rivojlantirib boriladi. Quyida rejalashtirilgan bosqichlar:

| Versiya | Holati | Tavsif |
|---|:---:|---|
| **v0.1** | ✅ Tayyor | Interpreter, Python-uslub sintaksis, 24 ta built-in, closures, massiv/obyektlar, CLI & REPL |
| **v0.2** | ⏳ Rejada | Modullar tizimi (`import "modul"`), fayllar bilan ishlash (`open`, `read`, `write`) |
| **v0.3** | ⏳ Rejada | Xatolarni tutish (`try / except`), yaxshilangan stacktrace va xato matnlari |
| **v0.4** | ⏳ Rejada | Statik ixtiyoriy tiplash (Gradual Typing) va linter |
| **v0.5** | ⏳ Rejada | LSP (Language Server Protocol) — VS Code plagin va autocompletion |
| **v0.6** | ⏳ Rejada | Bytecode VM — yuqori tezlik va optimallashgan virtual mashina |
| **v1.0** | ⏳ Rejada | Native / WebAssembly (WASM) kompilyatsiyasi |
